# Security policy

**Leonote desktop app**

## Reporting a vulnerability

If you find a security problem in Leonote, please report it privately to olexifyyy@gmail.com with "Leonote
security" in the subject, rather than in a public issue or on Discord. Include what you found, how to reproduce
it, and the Leonote version (Settings › About › Copy diagnostics) and Windows version you used.

Leonote is made by one person, so there is no set response time, but every report is read. Confirmed problems are
fixed with priority, and you can be credited in the changelog if you wish.

## Scope

Leonote has no server and no accounts, so reports concern the app itself: for example a note, a web page or a
file being able to run code in Leonote, read what it keeps (notes outside the vault, the password vault, API keys),
or make it send data somewhere it should not; or the local tools for AI agents (`--mcp`) doing more than a note's
AI access allows.

## Supported versions

Only the latest version (the Microsoft Store's and leonote.app's) receives fixes.
